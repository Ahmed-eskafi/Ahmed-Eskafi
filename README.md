## Featured Project

### [C3 Media Bridge](https://github.com/Ahmed-eskafi/c3-media-bridge)

An Android application designed to receive media-control commands from an ESP32-C3 over USB serial and translate them into Android media and volume actions.

**Highlights**
- ESP32-C3 USB Serial/JTAG communication
- Android media and volume controls
- Commands for play/pause, next, previous, volume up, and volume down
- Automated APK build workflow with GitHub Actions
